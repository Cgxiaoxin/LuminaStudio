# LuminaStudio 数据库文档（精简版）

> 数据库：MySQL · ORM：Prisma  
> 权威定义：`apps/server/prisma/schema.prisma`  
> 演示数据：`apps/server/prisma/seed.ts`

---

## 1. 设计约定

- 所有业务表带 `tenantId`（多租户隔离）
- 门店相关记录带 `storeId`
- 金额字段用 `Decimal`，不用浮点
- 密码仅存 `passwordHash`（bcrypt），不存明文
- 财务流水（LedgerEntry）只追加，不修改/删除

---

## 2. 表一览（15 张）

| # | 表名 | 中文 | 核心字段 | 说明 |
|---|------|------|----------|------|
| 1 | `Tenant` | 租户 | name, code, brandName, logoUrl | SaaS 品牌/租户 |
| 2 | `Store` | 门店 | name, address, phone, businessHours | 物理门店 |
| 3 | `AdminUser` | 后台账号 | username, passwordHash, role | 管理员/员工/教练 |
| 4 | `Client` | 小程序客户 | openid, phone, nickname | 微信用户，无密码 |
| 5 | `Service` | 课程服务 | name, type, price, durationMinutes | 团课/私教等定义 |
| 6 | `Schedule` | 排课 | startAt, endAt, capacity, bookedCount | 具体开课时段 |
| 7 | `Booking` | 预约 | bookingNo, status, source | 客户预约记录 |
| 8 | `Membership` | 会员卡 | type, remainingTimes, balanceAmount | 客户持有的卡 |
| 9 | `MembershipTemplate` | 卡种类模板 | name, type, price, totalTimes | 可售会员卡 SKU |
| 10 | `Order` | 订单 | orderNo, status, paidAmount | 付费/购卡订单 |
| 11 | `Payment` | 支付 | channel, amount, transactionId | 支付流水 |
| 12 | `LedgerEntry` | 账本 | type, amount, occurredAt | 充值/消费/退款等 |
| 13 | `CouponTemplate` | 优惠券模板 | couponType, discountValue | 营销券定义 |
| 14 | `ClientCoupon` | 客户优惠券 | status, issuedAt, usedAt | 已发放给客户的券 |
| 15 | `AuditLog` | 审计日志 | action, entityType, beforeData | 操作追溯 |

---

## 3. 按业务域分组

```
租户层     Tenant → Store
账号层     AdminUser（后台）  Client（小程序）
运营层     Service → Schedule → Booking
会员层     MembershipTemplate → Membership
财务层     Order → Payment → LedgerEntry
营销层     CouponTemplate → ClientCoupon
系统层     AuditLog
```

---

## 4. 关键状态枚举

| 枚举 | 取值 |
|------|------|
| 后台角色 `Role` | OWNER, ADMIN, STAFF, COACH |
| 预约 `BookingStatus` | CREATED → PENDING_PAYMENT → CONFIRMED → CHECKED_IN → COMPLETED / CANCELED |
| 排课 `ScheduleStatus` | OPEN, FULL, CANCELED, ARCHIVED |
| 订单 `OrderStatus` | PENDING, PAID, REFUNDED, CANCELED, FAILED |
| 会员卡 `MembershipType` | COUNT_BASED, DURATION_BASED, STORED_VALUE, HYBRID |

---

## 5. 主要关联

| 从 | 到 | 关系 |
|----|-----|------|
| Tenant | Store, AdminUser, Client… | 1 : N |
| Client | Booking, Membership, Order | 1 : N |
| Schedule | Booking | 1 : N |
| Booking | Order | 1 : N（付费场景） |
| Order | Payment | 1 : N |
| AdminUser (COACH) | Schedule, Service | 教练关联排课/课程 |

> 教练不单独建表，使用 `AdminUser.role = COACH`。

cd apps/server && npx prisma studio
