## 3. UI 设计规范（执行摘要）

> 完整规范见 `FRONTEND_DESIGN_SYSTEM.md`

### 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| background | `#f6f7f4` | 页面底 |
| surface | `#ffffff` | 卡片 |
| ink | `#17211c` | 主文字 |
| inkMuted | `#6f776f` | 次要文字 |
| primary | `#2e6f57` | 品牌绿、链接 |
| warning | `#c77700` | 名额紧张、待支付 |
| danger | `#c93d32` | 取消、错误 |

### 布局原则

- 每屏一个主决策（预约流：列表 → 详情 → 确认）
- 卡片圆角 `12rpx`，阴影 `0 4rpx 20rpx rgba(23,33,28,0.06)`
- 页内边距 `32rpx`
- 不用 emoji 作为正式图标（待替换为 SVG/PNG tab 图标）

### 组件状态（必须设计）

| 状态 | 视觉 | 文案示例 |
|------|------|----------|
| Loading | 骨架/Spinner | 「加载中…」 |
| Empty | 插画 + 说明 + CTA | 「暂无课程，去浏览课程」 |
| Error | 横幅 + 重试 | 「网络异常，点击重试」 |
| Success | Toast | 「预约成功」 |

## 4. 交互流程

### 4.1 预约主路径

```
首页/课程列表 → 课程详情 → 确认预约 → [支付] → 我的预约
```

| 步骤 | 用户操作 | 系统响应 |
|------|----------|----------|
| 选门店 | 首页 Picker | 持久化到 `stores/app.ts`，课程页读取 |
| 浏览 | 切换 Tab / 筛选 | `GET /schedules?storeId=&type=` |
| 详情 | 点击卡片 | `GET /schedules/:id` |
| 确认 | 选会员卡 / 付费 | `POST /bookings` |
| 支付 | 付费课 | dev：`POST /payments/notify/:id`；prod：`wx.requestPayment` |
| 查看 | 我的预约 Tab | `GET /bookings?status=` |

### 4.2 登录

- 未登录访问需鉴权接口 → 401 → `reLaunch` 登录页
- Profile 页可一键登录
- 登录后应 `GET /auth/me` 刷新用户信息

### 4.3 取消预约

- 待上课卡片展示「取消」
- `PATCH /bookings/:id/cancel`
- Toast 反馈 + 本地列表更新

## 5. API 对接清单

| 功能 | 方法 | 路径 | 页面 |
|------|------|------|------|
| 微信登录 | POST | `/auth/weapp-login` | login, profile |
| 当前用户 | GET | `/auth/me` | profile |
| 门店列表 | GET | `/stores` | home |
| 排课列表 | GET | `/schedules` | home, classes |
| 排课详情 | GET | `/schedules/:id` | class-detail |
| 创建预约 | POST | `/bookings` | booking-confirm |
| 我的预约 | GET | `/bookings` | bookings |
| 取消预约 | PATCH | `/bookings/:id/cancel` | bookings |
| 会员卡 | GET | `/memberships` | profile, booking-confirm |
| 统一下单 | POST | `/payments/unified-order` | booking-confirm |
| 支付回调 | POST | `/payments/notify/:id` | booking-confirm (dev) |

## 7. 与后端/Admin 协作要点

| 场景 | 小程序需求 | 后端/Admin |
|------|------------|------------|
| 课程为空 | 展示空状态 | Admin 创建 Service + Schedule |
| 预约失败「已满」 | Toast 错误码 | Schedules 容量校验 |

| 门店切换 | `storeId` 过滤 | Stores CRUD |
| Demo 数据 | — | `npm run db:setup` seed |
