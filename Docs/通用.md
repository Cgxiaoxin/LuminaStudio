## 1. 项目定位

LuminaStudio 是多租户普拉提/瑜伽工作室运营 SaaS，v1 聚焦「配置门店 → 发布排课 → 客户预约 → 支付/扣卡 → 核销 → 账本报表」日常闭环。

| 端 | 目录 | 技术栈 | 端口/产物 |
|----|------|--------|-----------|
| 后端 API | `apps/server` | NestJS + Prisma + MySQL | `:3000/api` |
| 管理后台 | `apps/admin` | React + Vite + Ant Design | `:5173` |
| 微信小程序 | `apps/miniapp` | Taro 4 + React | `apps/miniapp/dist` |

## 5. 协作约定

### 5.1 需求变更流程

1. PM 更新 `PRD.md` 或在本文件「差距表」标注
2. UI/交互更新 `FRONTEND_DESIGN_SYSTEM.md` 或各端 `.md`
3. 后端更新 `API_CATALOG.md` + 实现
4. 前端按端文档对接
5. 在 `DEV_LOG.md` 记录迭代

### 5.2 API 约定

- Base URL：`/api`
- 认证：`Authorization: Bearer <JWT>`
- 租户：`X-Tenant-Id` header（demo 默认 `1`）
- 错误：`{ code, message, details? }`

### 5.3 设计 token（两端共用）

见 `FRONTEND_DESIGN_SYSTEM.md` §5。小程序 SCSS 变量在 `apps/miniapp/src/styles/tokens.scss`。

### 5.4 本地联调快速启动

```bash
npm run db:setup          # MySQL + seed
npm run dev:server        # :3000
npm run dev:admin         # :5173
npm run dev:miniapp       # 微信开发者工具打开 dist
```

Admin 默认：`admin` / `admin123`，租户 ID `1`。
