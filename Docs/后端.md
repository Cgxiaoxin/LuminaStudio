## 1. 架构概览

```
apps/server/src/
├── main.ts                 # 全局前缀 /api、CORS、ValidationPipe
├── app.module.ts           # 15 业务模块
├── common/                 # Guards, Filters, Decorators
├── auth/                   # JWT + 微信登录
├── tenants/ stores/        # 租户、门店
├── staff/                  # AdminUser（含 COACH 角色）
├── customers/              # 客户（微信用户）
├── services/ schedules/    # 课程定义、排课
├── bookings/               # 预约核心（状态机 + 容量）
├── memberships/            # 会员卡
├── orders/ payments/       # 订单、支付
├── ledger/ reports/        # 账本、报表
└── marketing/              # 优惠券
```

### 设计原则

- **多租户**：所有业务表带 `tenantId`，请求头 `X-Tenant-Id`
- **模块化单体**：v1 不拆微服务
- **预约事务**：容量校验 + 乐观锁在同一事务
- **账本只追加**：Ledger 无 UPDATE/DELETE

## 3. 核心业务流

### 3.1 预约创建（三种路径）

```
POST /bookings
├── 免费课 → CONFIRMED
├── 会员卡 → 扣次 → CONFIRMED
└── 付费课 → PENDING_PAYMENT → 支付成功 → CONFIRMED
```

实现：`bookings.service.ts` — Prisma 事务内：

1. 校验 schedule 状态与容量
2. 原子更新 `bookedCount`
3. 创建 booking / order / membership 扣次

### 3.2 支付

```
POST /payments/unified-order  → 返回 prepay 参数
POST /payments/notify/:id     → 更新 order/booking + 写 ledger
```

- Dev：无微信凭证时自动 mock 成功
- Prod：需 `WECHAT_APPID`, `WECHAT_MCH_ID`, 证书等

### 3.3 微信登录

```
POST /auth/weapp-login { code }
→ code2Session → upsert Client → JWT
```

- Dev：无 AppSecret 时用 code hash 生成稳定 `dev_*` openid
- Prod：配置 `WECHAT_APPID` + `WECHAT_SECRET`

## 4. 数据模型速查

| 模型 | 说明 |
|------|------|
| Tenant | 租户（工作室品牌） |
| Store | 门店 |
| AdminUser | 后台用户 + 教练（role=COACH） |
| Client | 小程序用户 |
| Service | 课程/私教定义 |
| Schedule | 排课实例（容量、时间） |
| Booking | 预约（状态机） |
| Membership | 会员卡 |
| Order | 付费订单 |
| Payment | 支付记录 |
| LedgerEntry | 财务流水 |
| CouponTemplate / ClientCoupon | 优惠券 |

完整字段见 `DATABASE_MODEL.md` 与 `prisma/schema.prisma`。

### Booking 状态机

```
CREATED → PENDING_PAYMENT → CONFIRMED → CHECKED_IN → COMPLETED
                              ↘ CANCELED
```

## 6. 与前端协作

### 请求头

```http
Authorization: Bearer <jwt>
X-Tenant-Id: 1
Content-Type: application/json
```

### 错误响应

```json
{
  "code": "SCHEDULE_FULL",
  "message": "该时段已满",
  "details": {}
}
```

### Seed 数据

```bash
npm run db:setup   # push + seed
```

默认：租户 1、2 门店、管理员 admin/admin123、示例排课。
