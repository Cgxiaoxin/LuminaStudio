## 3. UI / 交互规范（Admin）

> 完整规范见 `FRONTEND_DESIGN_SYSTEM.md`

### 设计原则

- **运营优先**：表格 + 筛选 + 状态 Tag + 行内操作
- **信息密度高**：14px 基准字号，紧凑行高
- **租户/门店上下文**：顶栏或筛选区始终可见当前范围

### 列表页标准状态

| 状态 | 实现 |
|------|------|
| Loading | Ant Design `Table` loading 或 Skeleton |
| Empty | `Empty` 组件 + 「创建」或「重置筛选」 |
| Error | `message.error` + 重试按钮 |
| 筛选 | 日期/门店/状态保留在 URL 或 local state |

### 状态 Tag 色彩

与 `FRONTEND_DESIGN_SYSTEM.md` StatusTag 一致：

- 成功：已支付、已核销、有效
- 警告：待支付、已创建
- 危险：已取消、失败、过期

## 4. 各页功能与 API

| 页面 | 主要 API | 核心操作 |
|------|----------|----------|
| Dashboard | `GET /reports/dashboard` | 今日预约/收入概览 |
| Stores | CRUD `/stores` | 门店 CRUD |
| Staff | CRUD `/admin-users` | 员工/教练 + 角色 |
| Services | CRUD `/services` | 团课/私教定义 |
| Schedules | CRUD `/schedules` | 排课、容量 |
| Bookings | `GET/PATCH /bookings` | 列表、核销、取消 |
| Memberships | CRUD `/memberships` | 发卡、退卡 |
| Finance | `GET /orders`, `GET /ledger` | 订单 + 流水 |
| Reports | `GET /reports/*` | 指标卡片 |
| Marketing | CRUD `/coupon-templates` | 优惠券模板 |

## 5. 日常运营流（Admin ↔ 小程序）

```
1. Admin：创建 Service（课程） + Schedule（排课）
2. 小程序：客户浏览 → 预约
3. Admin：Bookings 页核销 CHECKED_IN
4. Admin：Reports / Finance 查看结果
```
